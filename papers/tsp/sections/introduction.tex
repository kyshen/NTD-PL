\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{M}{ultidimensional} signals often contain strong structure across
space, spectrum, time, view, or acquisition mode. Low-rank tensor models
exploit this structure by representing a signal through a small number of
coupled low-dimensional factors. They have become standard tools for signal
representation, denoising, completion, and recovery
\cite{Kolda2009Tensor,Sidiropoulos2017TSP,Liu2013TensorCompletion,
LiuMoitra2020TensorCompletion}. Tucker decomposition is especially useful in
this setting because it separates a compact core from mode-wise factors and
provides an explicit multilinear rank budget.

In many sensing pipelines, however, the structured signal and the recorded
data are not on the same scale. Camera response curves, radiometric processing,
and saturation are direct examples of nonlinear transformations before data
storage \cite{Debevec1997HDR,Grossberg2004CameraResponse}. Post-nonlinear
hyperspectral mixing provides a related precedent in which a lower-dimensional
signal is transformed after a structured mixing stage
\cite{BioucasDias2012HyperspectralUnmixing,Altmann2012PostNonlinear,
Heylen2014NonlinearUnmixing}. These processes have different physical origins,
but they motivate the same question: what happens when a compact tensor signal
is observed after a nonlinear response? Related questions also arise in
generalized low-rank and single-index matrix models
\cite{Udell2016GLRM,Ganti2015SingleIndex}.

For a fixed-rank Tucker model, this distinction matters because an entrywise
nonlinear response can increase the apparent multilinear rank of the measured
tensor. A low-rank signal before the response may therefore require a much
larger Tucker rank if the measured tensor is modeled directly. This creates a
specific mismatch: the selected rank can be suitable for the latent signal
while a Tucker model with the same rank is insufficient for the measurements.

Increasing the Tucker rank can reduce this mismatch, but it changes the whole
multilinear representation: the core grows rapidly and every mode factor gains
additional degrees of freedom. More general functional, kernel, and neural
tensor models can describe a broader range of nonlinear effects
\cite{Luo2024LRTFR,saragadam2024deeptensor,ahn2024neural}. Our goal is a more
structured model that keeps a clear Tucker rank budget while allowing
higher-order interactions.

We begin from the Tucker model itself. For fixed mode factors, standard Tucker
maps the core linearly to the data tensor. We extend this map by introducing a
\emph{$p$-fold Tucker term}, which combines $p$ copies of the core through
higher-order mode maps. The case $p=1$ is standard Tucker, and a sum over
several orders gives a \emph{Tucker polynomial}. This is a direct nonlinear
extension of the core map, but the general form needs new mode maps at every
order and quickly becomes large.

The model becomes compact when the same Tucker factors are shared across all
orders. Let
\begin{equation}
  \cS =
  \tucker{\cX}{\bA^{(1)},\ldots,\bA^{(N)}}
\end{equation}
be the Tucker tensor formed by the shared factors. Under this sharing, the
degree-$p$ Tucker term is exactly $\cS^{\od p}$. The resulting model is
\begin{equation}
  \widehat{\cY}
  =
  \sum_{p=0}^{P}\beta_p\cS^{\od p}
  =
  f_{\bbeta}(\cS),
  \label{eq:intro_ntdpl}
\end{equation}
which we call nonlinear Tucker decomposition with polynomial links (NTD-PL).
Compared with the general Tucker polynomial, NTD-PL reuses one core and one set
of factors and adds only the scalar coefficients
$\bbeta=(\beta_0,\ldots,\beta_P)$.

This derivation gives NTD-PL two complementary interpretations. It is the
shared-factor form of the Tucker polynomial, and it is also a low-rank Tucker
tensor followed by an entrywise polynomial response. The first view explains
where the higher-order interactions come from. The second connects the model
to nonlinear measurements. The same estimator can replace the powers by other
finite sets of scalar basis functions when a different response basis is
appropriate.

The Tucker parameters and response coefficients are estimated jointly from the
observed entries of the measured tensor $\cY$. The objective fits available
measurements and predicts missing entries while using $\cS$ as a compact latent
representation. Without external calibration constraints, the decomposition
into $\cS$ and $f_{\bbeta}$ need not identify a unique physical pre-response
signal; the fitted pair is interpreted through its prediction of $\cY$.

Sharing the factors greatly reduces the parameter count, but it does not remove
the high-order effect. Each $\cS^{\od p}$ has a Tucker representation whose
factors contain degree-$p$ monomials of the shared factors. The measured tensor
can therefore have higher effective rank while the latent Tucker ranks remain
fixed. The model is useful when these shared higher-order terms explain a
substantial part of the Tucker residual. If they do not, increasing the Tucker
rank or changing the tensor prior is a more direct remedy.

We fit the shared-factor model with a masked least-squares objective. The
estimator alternates between a small ridge regression for the response
coefficients and gradient-based updates of the Tucker core and factors. We also
introduce a low-cost diagnostic: after fitting a linear Tucker model, we keep
it fixed, refit only the response coefficients, and measure the residual
reduction. A large reduction indicates that joint NTD-PL training is more
likely to be useful.

\subsection{Contributions}
\label{subsec:contributions}

The main contributions are summarized as follows.
\begin{itemize}
  \item We introduce the Tucker polynomial, which extends the linear core map
  of Tucker decomposition with $p$-fold interactions. Sharing the mode factors
  across orders yields NTD-PL, a compact model for nonlinear tensor
  measurements.

  \item We develop a masked alternating estimator for the shared-factor model,
  with a closed-form ridge update for the response coefficients and descent
  updates for the Tucker parameters. We also propose a diagnostic that measures
  how much of a fixed Tucker residual can be removed by refitting only the
  response.

  \item We establish the relation between $p$-fold Tucker terms and NTD-PL,
  analyze the induced rank inflation and parameter cost, prove approximation of
  continuous responses, and study stationarity and computational scaling.

  \item We evaluate controlled nonlinear measurements, CAVE
  reconstruction and completion, noisy reconstruction, and cross-domain
  diagnostics. Comparisons with matched-rank and higher-rank Tucker, CP, and TT
  test accuracy and parameter use, while mechanism experiments connect the
  gains to the measured rank increase and to the response diagnostic score.
\end{itemize}
